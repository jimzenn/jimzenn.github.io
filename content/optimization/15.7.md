{{% definition name="Optimal feasible solution" status="" %}}

Any vector $\b{x} $ that yields the minimum value of the objective function $\transpose{ \b{c}}\b{x} $ over the set of vectors satisfying the constraints $\b{Ax = b, x \geq 0} $ is said to be an **optimal feasible solution**.

{{% /definition %}}

{{% theorem name="Fundamental Theorem of LP" index="" status="" %}}

Consider a linear program in standard form.

1. If there exists a feasible solution, then there exists a basic feasible solution.

2. If there exists an optimal feasible solution, then there exists an optimal basic feasible solution.

{{% /theorem %}}
