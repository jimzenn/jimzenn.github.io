{{% definition name="Real Vector Spaces" status="" %}}

1. A column n-vector $a $ is an array of numbers $a {\Vce{ a\_1 }{ \vdots }{ a\_n }} $
2. $R^n $ the set of column n-vectors
3. $a + b = {\Vcr{ a\_1 + b\_1 }{ a\_2 + b\_2 }{ \vdots }{ a\_n + b\_n }} $
4. A set of vectors $\set{ a\_1, ..., a\_k } \subseteq \R^n$ is linearly independent if $\alpha\_1a\_1 + \alpha\_2a\_2 + ... + \alpha\_{ k }a\_{ k } = 0 $ implies $\alpha\_1 = 0, 0, ..., a\_k = 0 $
5. A vector $a $ in a linear combination of $\set{ a, ..., a\_k } $ if $a = \alpha\_1a\_1 + \alpha\_2a\_2 + ... + \alpha\_{ k }a\_{ k } $
6. $ V \subseteq R^n $ is a subspace of $ R^n $ if $ V $ is closed under vector addition and scalar multiplication.

{{% note name="" %}}

$\set{ a\_1, ..., a\_k }$ are linearly dependent $\iff$ one of the vectors is a linear combination of the others.
