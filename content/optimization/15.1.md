{{% definition name="Linear programming problems" status="" %}}

A linear programming problem is a special case of a general constrained optimization problem. 

In the general setting, the goal is to find a point that minimizes the objective function and at the same time satisfies the constraints. We refer to any point that satisfies the constraints as a **feasible point**.

In a linear programming problem, the objective function is <u>linear</u> and the set of feasible points is determined by <u>a set of linear equations and / or inequalities</u>.
