{{% definition name="affine function" status="" %}}

Differential calculus is based on the idea of approximating an arbitrary function by an **affine function**.

A function $\mathcal{A}: \R^n \to \R^m $ is **affine** if there exists a linear function $\mathcal{L}: \R^n \to \R^m $ and a vector $ y \in \R^m $ such that

$$\mathcal{A}(x) = \mathcal{L}(x) + y $$

for every $\b{ x } \in \R^n $.
